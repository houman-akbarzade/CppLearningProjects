# CppLearningProjects

این ریپازیتوری مجموعه‌ای از پروژه‌های کوچک C++ است که به عنوان بخشی از فرایند یادگیری زبان C++ و آماده‌سازی برای توسعه HLS ایجاد شده است. هدف اصلی از ایجاد این پروژه، تمرین مفاهیم مختلف زبان C++ و آشنایی با ساختارهای داده و الگوریتم‌های مختلف است.

**هدف:**
* یادگیری زبان C++
* تمرین مفاهیم اولیه برنامه‌نویسی به زبان C++
* آماده‌سازی برای توسعه HLS

**محتوا:**
این ریپازیتوری شامل پروژه‌های متنوعی است که ممکن است به ظاهر بی‌ارتباط به نظر برسند. این پروژه‌ها معمولاً تمرین‌های کوچکی هستند که برای یادگیری یک مفهوم خاص طراحی شده‌اند.

**نحوه استفاده:**
این پروژه برای استفاده شخصی طراحی شده است و نیازی به نصب یا پیکربندی خاصی ندارد. شما می‌توانید هر فایل C++ را به صورت جداگانه کامپایل و اجرا کنید.

**مشارکت:**
در حال حاضر، هیچ برنامه‌ای برای مشارکت دیگران در این پروژه وجود ندارد.

**مجوز:**
این پروژه تحت مجوز MIT منتشر شده است.
