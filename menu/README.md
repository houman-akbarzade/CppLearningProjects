# تمرین‌های پوشه `menu`

این پوشه شامل تمرین‌های مرتبط با کار با آرایه‌ها، بردارها (vectors)، و استفاده از منو برای عملیات مختلف است. تمرین‌های موجود در این بخش به شما کمک می‌کنند تا مهارت‌های پایه‌ای خود در زبان C++ را تقویت کرده و با مفاهیم زیر آشنا شوید:

## تمرین‌ها

### تمرین ۱: اضافه کردن و حذف عناصر به بردار

- **شرح**: برنامه‌ای با قابلیت افزودن و حذف عناصر به/از یک بردار (vector).
- **اهداف یادگیری**:
  - استفاده از کلاس `std::vector` برای مدیریت داده‌های پویا.
  - آشنایی با توابع `push_back` و `erase`.
  - پیاده‌سازی یک منو برای انتخاب عملیات مختلف.
- **فایل مربوطه**: `menu.cpp`

### تمرین ۲: مرتب‌سازی بردار

- **شرح**: برنامه‌ای برای مرتب‌سازی عناصر یک بردار.
- **اهداف یادگیری**:
  - استفاده از توابع مرتب‌سازی دستی (پیاده‌سازی bubble sort یا سایر الگوریتم‌ها).
  - کار با اشاره‌گرها و مراجع (References) برای ارسال بردار به توابع.

### تمرین ۳: جستجو در بردار

- **شرح**: جستجوی یک مقدار خاص در یک بردار.
- **اهداف یادگیری**:
  - استفاده از حلقه‌ها برای پیمایش بردار.
  - پیاده‌سازی جستجوی خطی و آشنایی با اصول الگوریتمی.

### تمرین ۴: میانگین‌گیری مقادیر

- **شرح**: محاسبه میانگین مقادیر موجود در بردار.
- **اهداف یادگیری**:
  - جمع‌آوری داده‌ها در بردار.
  - استفاده از حلقه برای محاسبه مجموع.
  - استفاده از متد `size` بردار برای محاسبات.

## روش اجرا

1. فایل‌های تمرین را در این پوشه ذخیره کنید.
2. از طریق ترمینال، به مسیر پروژه بروید و دستور زیر را اجرا کنید:

```bash
cd menu
g++ menu.cpp -o menu
./menu
```

## نکات مهم

- تمامی تغییرات در بردار به صورت پویا اعمال می‌شود.
- از ابزارهای استاندارد STL مانند `std::vector` استفاده شده است.
- برای مرتب‌سازی دستی از الگوریتم ساده استفاده شده، اما می‌توانید از توابع آماده مانند `std::sort` نیز بهره ببرید.

## نکات برای توسعه

- می‌توانید منو را گسترش دهید تا عملیات بیشتری مانند یافتن حداقل و حداکثر مقادیر را نیز شامل شود.
- از کاربران ورودی‌های عددی معتبر درخواست کنید و مقادیر اشتباه را مدیریت کنید.

## نکات آموخته‌شده

- تفاوت ارسال مقادیر به توابع با استفاده از مراجع (references) به جای کپی کردن داده‌ها.
- استفاده از حلقه‌های `for-each` برای پیمایش بردارها.
- ترکیب چندین عملیات و پیاده‌سازی منو در یک برنامه‌ی کامل.
